Quick start

Create an account, receive a session cookie, then call workspace-scoped resources. Credentials are never returned in JSON — only via Set-Cookie.

curl -sS -c cookies.txt -X POST "$API/v1/auth/signup" \
  -H 'content-type: application/json' \
  -d '{
    "email": "ops@acme.example",
    "password": "choose-a-long-passphrase",
    "workspaceName": "Acme Listening"
  }'

curl -sS -b cookies.txt "$API/v1/workspaces"
curl -sS -b cookies.txt "$API/v1/me"

Production dashboard calls the same origin path prefix /api. Local QA defaults to http://<host>:8787.

All examples below use $API as the chosen base. Paths are absolute from that base (e.g. $API/v1/me).

Authentication

PulseWatch uses HTTP-only session cookies. There is no public bearer-token minting in v1.

  • Cookie name: reputa_session (overridable via SESSION_COOKIE_NAME)
  • Value shape: <userShard>.<sessionId>.<sessionSecret>
  • Flags: HttpOnly, SameSite=Lax, Path=/; Secure only on production / staging
  • Clients must send credentials: "include" (browser) or -b / -c cookie jars (curl)

CORS

Credentialed CORS is allowed only for origins listed in ALLOWED_ORIGINS (comma-separated). Preflight: OPTIONS with Access-Control-Allow-Credentials: true. Disallowed origins do not receive ACAO.

await fetch(`${apiBase}/v1/me`, {
  credentials: "include",
  headers: { "content-type": "application/json" }
});

Conventions

  • Content type: request bodies are JSON (content-type: application/json)
  • Response type: JSON objects; list resources use plural keys (monitors, mentions, alerts)
  • IDs: UUIDs for workspaces, monitors, sessions
  • Request tracing: every response includes x-request-id
  • Timestamps: ISO-8601 UTC strings where present
  • Idempotency: billing webhook events are stored by eventId and may return duplicate: true

Errors

Failures return a JSON body with an error string (machine-oriented) and HTTP status. Do not parse human prose from status text alone.

{
  "error": "forbidden",
  "requestId": "a284b62a4df8acf6"
}

Admin

Requires globalRole: "super_admin". Never expose a public signup path into this role.

GET /v1/admin/tenants super_admin

Lists tenant registry entries from CONFIG_KV keys written on workspace create.

GET /v1/admin/source-health super_admin

Platform source-health snapshot (same shape as public source-health; gated for ops consoles).

Boolean query language

  • Operators: AND, OR, NOT (precedence NOT > AND > OR)
  • Implicit AND between adjacent terms
  • Quoted phrases for exact match, including Vietnamese Unicode
  • Parentheses for grouping
  • Validate with POST /v1/queries/validate before create
"Công ty Acme" AND (kiện OR scandal) AND NOT "Acme School"

After crawl/fetch, queries are re-evaluated against extracted text — discovery candidates alone are not trusted for final match.

Versioning

All product routes live under /v1. Breaking changes ship as a new major prefix. Additive fields may appear in existing responses without a version bump. Prefer tolerant clients.

Generated for the PulseWatch Cloudflare Workers control plane. Internal Durable Object paths (/internal/*) are not part of the public contract.
