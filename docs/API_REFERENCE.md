# PulseWatch HTTP API Reference

Canonical interactive documentation ships with the dashboard:

- Local: `http://127.0.0.1:8788/docs/index.html`
- Production: `https://reputation.orangecloud.vn/docs/index.html`
- workers.dev: `https://reputa-dashboard-production.sycu-lee.workers.dev/docs/index.html`

The page documents authentication (session cookies), RBAC capabilities, entitlements, Boolean queries, and every public `/v1` route implemented by `apps/api-worker`.

Internal Durable Object paths (`/internal/*`) are not part of the public contract.
